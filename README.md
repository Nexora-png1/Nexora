# NEXORA

**Smart Food Quality & Safety Analyzer**

**SIH Problem Statement:** SIH26034
**Theme:** MedTech / BioTech / HealthTech

## Why NEXORA?

Packaged-food labels contain important nutrition, ingredient, allergen, and safety information, but they can be difficult to understand quickly. **NEXORA** simplifies this information, checks product details, provides personalized food insights, and helps users make safer and more informed choices.
